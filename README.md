# Deep Learning

This repository contains a progressive collection of Jupyter notebooks for
learning deep learning with Python, TensorFlow/Keras, NumPy, pandas, and
scikit-learn. The notebooks are arranged in phases, moving from basic
perceptrons and neural networks to convolutional and recurrent neural
networks.

## Getting started

1. Clone the repository and open it in VS Code or JupyterLab.
2. Create and select a Python environment with the packages used by the
   notebooks:

   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn tensorflow keras mlxtend jupyter
   ```

3. Start with [L7](./1first_phase/L7.ipynb), then work through the phases in
   order.
4. Run each notebook with a compatible Python kernel. Some notebooks download
   datasets through Keras, including MNIST and IMDB.

Some notebooks refer to datasets outside this repository (for example
`ML/datasets/add_pred.csv`, `ML/datasets/sal_par.csv`,
`ML/datasets/placement.csv`, and `datasets/concentric_circle.csv`). Those
files must be available at the paths expected by the individual notebook
before it is executed.

## Learning path

The recommended progression is:

1. Understand linear decision boundaries and perceptrons.
2. Build dense networks for classification and regression.
3. Implement backpropagation and learn training improvements.
4. Study scaling, initialization, regularization, early stopping, batch
   normalization, and hyperparameter tuning.
5. Learn convolution, padding, strides, pooling, and image classification.
6. Explore transfer learning, CNN visualization, tokenization, and embeddings.
7. Build recurrent models for sentiment analysis and next-word prediction.
